UFO Sightings — Enterprise Data Warehouse & BI Solution

Featured

Academic project · NOVA IMS · Microsoft Fabric, Power BI

An end-to-end dimensional data warehouse built on a public UFO sightings dataset to simulate an enterprise BI architecture — from raw ingestion to a business-ready semantic model and dashboard.

  • Architecture: designed a Lakehouse → staging → data warehouse layered architecture in Microsoft Fabric.
  • Modelling: applied Kimball dimensional methodology — defined the grain, implemented fact and dimension tables, created surrogate keys and lookup transformations.
  • ETL: cleansed, normalised and transformed data with Fabric Dataflows, and orchestrated the full ETL process with Fabric Pipelines.
  • Semantic model: renamed and organised attributes for clarity and adoption by non-technical users, and built hierarchies for intuitive drill-down analysis.
  • Analytics: authored reusable DAX measures for key business metrics and delivered an interactive dashboard aligned to defined business requirements.
